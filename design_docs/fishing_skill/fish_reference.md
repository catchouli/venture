# Fish Reference List

> Species pool for `fishing.md`. **Worldwide scope** — real species organized by water type and home region, so game regions/continents can each have their own fauna. **No game stats here** — XP, levels and methods live in fishing.md; this file is the raw pool to pick from.
>
> Entries marked ✱ are already used in the fishing.md fish table. Region tags: **[EU]** Europe/UK · **[NA]** North America · **[SA]** South America · **[AF]** Africa · **[AS]** Asia · **[OC]** Oceania/Australasia · **[AR]** Arctic/subarctic · **[W]** worldwide oceans.
>
> Size classes: **Tiny** <15 cm · **Small** 15–30 cm · **Med** 30–60 cm · **Large** 60–100 cm · **Trophy** 100 cm+
>
> Sources: Wikipedia freshwater/marine game fish lists · Canal & River Trust · FishBase · British Record Fish Committee · WWF Amazon fish guide · IGFA game fish database · NSW DPI species list.

## Count summary

- Freshwater: ~120 species across six regions (EU, NA, SA, AF, AS, OC + Arctic)
- Saltwater: ~170 species across home waters + worldwide game/reef/shark/Australasia/Arctic/deepwater
- Shellfish: ~40 species
- Migratory & brackish: ~20 species

## Design hooks worth remembering

- **Regions as biomes**: each freshwater/saltwater region above can be a game region — a continent-level map where local species replace the home-water equivalents at the same level bands (e.g. largemouth bass = the NA perch slot; peacock bass = the SA lure slot; barramundi = the OC estuary slot).
- **Trap/pot content** maps cleanly onto shellfish — crab, lobster, langoustine, shrimp already exist there. Freshwater cage traps use the dedicated **Freshwater trap critters** table (crayfish worldwide, mitten crabs, prawns, snails, mussels).
- **Water types are two**: freshwater (rivers & lakes) and saltwater (sea) — the game has no estuary type. Real estuary/brackish species were assigned to whichever side fits their fishing style (mullet, flounder, smelt, whitebait → sea; migratory runners → river events).
- **Migratory runs** (salmon, sea trout, striped bass, whitebait) are natural seasonal event catches.
- **Rare/protected/no-catch species** (great white, whale shark, manta, sawfish, beluga sturgeon, coelacanth, oarfish) are quest/sighting/conservation content, not standard catches.
- **Deepwater shelf list** is a ready-made 71–99 content bucket.
- Cast-net shoal fish: sprat, whitebait, pilchard, herring, sandeel, anchovy, capelin — Tiny–Small schooling species in any warm/cold coast.
