# Venture

A medieval fantasy MMORPG in Rust, inspired by the worlds of **Lineage 2** and
**Old School RuneScape**: a large, lush, hazy world to explore on foot, with
distinct lands for each of its peoples and a deep set of skills.

The client runs in the web browser (WebAssembly) and on the desktop, with mobile
planned. The world is generated by a deterministic procedural engine, with
authored content layered on top.

> **Status:** early prototype. The world generation engine works, and the
> client streams and renders the terrain with a character you can click to run
> around. There is no other gameplay yet.

## Quick start

```sh
# Desktop client
cargo run -p venture_client

# Web client (then open http://127.0.0.1:8080)
rustup target add wasm32-unknown-unknown
cargo install --locked trunk
cd crates/client && trunk serve

# Render the whole world to PNG maps in preview/
cargo run --release -p venture_worldgen --example preview

# Tests and checks
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --check
```

Controls: **left-click** the ground to run there, or run with **WASD**
(relative to the camera). **Right-drag** or the **arrow keys** rotate and tilt
the camera, and the **mouse wheel** zooms. **F1** switches to a free camera for flying around (**WASD** to move,
**Shift** to go faster).
