# Venture

A medieval fantasy MMORPG in Rust, inspired by the worlds of **Lineage 2** and
**Old School RuneScape**: a large, lush, hazy world to explore on foot, with
distinct lands for each of its peoples and a deep set of skills.

The client runs in the web browser (WebAssembly) and on the desktop, with mobile
planned. The world is generated by a deterministic procedural engine, with
authored content layered on top.

> **Status:** early prototype. A deterministic world generation engine, and
> an authoritative server you can play on with friends over your local
> network: run around, see each other, chat, and meet scripted NPCs in the
> starting town. Content (NPCs, looks, scripts) reloads live as you edit it.

## Quick start

```sh
# One-time setup for the web client
rustup target add wasm32-unknown-unknown
cargo install --locked trunk

# 1. Bake the world (about 10 seconds; writes the world/ folder)
cargo run --release -p venture_worldgen --bin bake

# 2. Build the web client
(cd crates/client && trunk build --release --cargo-profile wasm-release)

# 3. Run the server, then open the address it prints in a browser
cargo run --release -p venture_server
```

Others on your network can join by opening the "On your network" address.
Server settings, such as the port and game rules, are in `server.ron`. NPCs
and their scripts are in `content/`; check them with
`cargo run -p venture_content --features scripts --bin check`.

Desktop client: `cargo run -p venture_client` connects to a server on this
computer (`--connect http://host:port` for another), and
`cargo run -p venture_client -- --local` runs a server inside the client, for
working without a separate server.

Checks: `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`
and `cargo fmt --check`.

Controls: **left-click** the ground to run there, or run with **WASD**
(relative to the camera), and **Space** jumps. **Right-drag** or the **arrow keys** rotate and tilt
the camera, and the **mouse wheel** zooms. Click a player, NPC or monster to **select**
it; click again to **follow** a player, **talk** to an NPC or **attack** a monster. **Escape** deselects. **Enter** chats. The character window's tabs each have a key (and a button on the toolbar, top right): **C** stats,
**K** skills, **L** abilities, **I** inventory, **G** gear, **J** quests, **O** emotes.
The **hotbar** down the bottom right uses abilities and actions with keys **1** to **0**
(or a click). Drag abilities and actions onto it from the character window.
New players choose a name, a class (Fighter or Mage) and a body type, with a
preview. Talking to an NPC opens a **dialogue window**. Type **/help** in chat for commands such as **/follow**, **/talk**, **/attack**, **/wave** and **/town**. Rabbits live around the town and goblins (which attack on sight) a little further out; your health is at the top left, and if you're knocked out you wake up in town.
Admins (listed by name in `server.ron`) also have **/setlevel**, **/reset**, **/setclass** and **/setgender**. **F3** shows
debug information, and while it's showing **F1** switches to a free camera for flying around (**WASD** to
move, **Shift** to go faster).

## Repository layout

```
crates/
  world/     venture_world     Core world data: coordinates, chunks, terrain cells, props
  worldgen/  venture_worldgen  The world generation engine
  navigation/ venture_navigation Where characters can walk, and pathfinding
  simulation/ venture_simulation Game rules shared by server and client (movement)
  rpg/       venture_rpg       The RPG rules: stats, levels, health, attacks (SRD 5.1 based)
  protocol/  venture_protocol  Messages between client and server
  content/   venture_content   The content pack: definitions, checking, client manifest
  server/    venture_server    The authoritative game server (also hosts the web client)
  client/    venture_client    The Bevy game client (browser and desktop)
content/                       The content pack: classes, NPCs, items, shops, quests, scripts, dialogue
tools/                         Development tools (placeholder icons)
docs/                          Design and technical documentation
```
